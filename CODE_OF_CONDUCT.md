# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies in full to this repository.

To report unacceptable behavior, open an issue asking for a private channel without including
details, or report via [JakobMelchard security policy](https://github.com/JakobMelchard/.github/blob/main/SECURITY.md)
marked as a conduct issue. Reports are handled by the maintainer, Jakob Melchard.
